## About this app

A tvOS-inspired Minimal Android TV launcher with a clean, cinematic
interface and powerful Android customization.

Transform your Android TV home screen with a modern launcher inspired by
the simplicity and smooth navigation of tvOS, while keeping the
flexibility and customization Android users expect.

### Minimal Experience

-   Clean, cinematic home screen
-   Apple TV-inspired layout and visual style
-   Easy navigation with your TV remote
-   Fast and responsive interface

### Favorites & All Apps

-   Customizable Favorites row
-   Choose apps per row
-   Easily move apps between Favorites, All Apps, and folders
-   Reorder apps
-   Organize apps and folders exactly how you want

### Deep Customization

-   Custom wallpapers
-   Video wallpapers
-   Wallpaper blur controls
-   Custom gradient backgrounds
-   Dark and light themes
-   Custom app icons
-   Icon pack support
-   Rename apps
-   Hide apps

### App Management

-   Rename apps
-   Change individual app icons
-   Support for icon packs
-   Hide unwanted apps
-   Uninstall apps
-   Open Android App Info
-   Create and organize folders
-   Add and remove apps from folders
-   Persistent app ordering

### Folders & Organization

Keep your apps organized with folders designed for TV navigation.

-   Create folders
-   Add apps to folders
-   Rename folders
-   Organize apps using D-pad navigation
-   Smooth folder interface

### Media & Hero Experience

-   Customizable hero section
-   Watch Next support
-   Focus-based media loading
-   Configurable media visibility
-   Smooth transitions between content sections

### Powerful Layout Controls

Make the launcher fit your TV and your preferences.

### Consistent Visual Design

### Accessibility Service Notice

OxTV Launcher includes an optional accessibility service, solely used to
improve navigation by allowing custom actions via remote control
shortcuts. No data is collected or shared.
